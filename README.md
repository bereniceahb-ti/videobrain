# VideoBrain

Biblioteca pessoal inteligente para transformar vídeos salvos do YouTube em conhecimento útil.

## MVP
- Entrada por vários screenshots da lista do YouTube
- Entrada alternativa por múltiplos links
- Confirmação antes de processar
- Biblioteca visual com thumbnails, categorias, busca e favoritos
- Resumos e organização por IA (próxima integração)

## Desenvolvimento
```bash
npm install
npm run dev
```

O projeto foi desenhado mobile-first e preparado para Next.js + Vercel + Supabase.
